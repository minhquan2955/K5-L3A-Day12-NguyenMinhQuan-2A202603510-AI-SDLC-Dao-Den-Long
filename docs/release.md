# Đảo Đèn Lồng v1.0.0

Bản web có sẵn Three.js. Giải nén `dao-den-long-v1.0.0.zip`, mở terminal trong thư mục `dao-den-long` và chạy `node server.js` với Node.js 20.18.3 trở lên. Mở http://127.0.0.1:3000 trên trình duyệt hỗ trợ WebGL 2. Bảng điểm được lưu trong thư mục game.

Giữ ít nhất 60% đèn sáng tới bình minh trong mỗi đêm. Phase 4 thêm bảng điểm cục bộ, đổi phím, chữ lớn, giảm chuyển động và chỉ báo nguy hiểm bằng hình.
